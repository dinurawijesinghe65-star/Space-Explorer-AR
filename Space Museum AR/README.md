# Space Explorer Mini Exhibit

An AR.js + A-Frame themed scene on the Hiro marker.

## Features
- 5 objects on the marker: glTF astronaut, sphere, box, cylinder, and a-text label.
- Two different animations: rotation (astronaut & box) and position bobbing (sphere).
- Tap the **blue sphere** → changes colour (workshop component).
- Tap the **red box** → toggles visibility (new custom component).
- Status banner changes colour and text when the marker is found/lost.

Deployed via [Netlify Drop](https://app.netlify.com/drop) / GitHub Pages (HTTPS enabled).

## How to Run
1. Serve the folder over HTTPS (or `localhost`).
2. Open the page on a phone.
3. Point the camera at the **Hiro marker**.
4. Tap the sphere or box to interact.
